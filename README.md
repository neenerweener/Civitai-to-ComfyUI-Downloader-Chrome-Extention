I got tired of there only being paid addons to quickly download files and automatically sort them into the appropriate folders from Civitai.com and civitai.red
This addon adds an extra download button underneath the original.
You will need an API key from CivitAI in order to download the spicier models automaticly.

To install download the entire repository and unpack it. 
Run "Link-ComfyUI-Folder.bat"
Then go to chrome://extensions -> Click Load unpacked
Select the folder you unpacked it in.
Edit the download location
Add your API key
Download all the things! \o/
